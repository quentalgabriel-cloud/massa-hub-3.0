# FeelWorks Engineering Handbook

> A constituição viva da FeelWorks — equivalente a AWS Well-Architected Framework, Google Material Design, Shopify Polaris, Stripe Engineering Handbook e Linear Handbook.

Este handbook não é documentação. É **como a FeelWorks pensa**.

Quando alguém (especialmente Claude Code) abre este handbook, não aprende telas — aprende a DNA da empresa.

## Como Ler Este Handbook

**Para Claude Code:**
1. Comece por [00 — Foundation](./docs/00_FOUNDATION/)
2. Leia [MentalModels](./docs/00_FOUNDATION/MentalModels.md) com atenção
3. Depois visite as seções relevantes à sua tarefa
4. Sempre cruze decisões com [Principles](./docs/00_FOUNDATION/Principles.md)

**Para novos membros do time:**
1. Leia Vision + Manifesto (15 min)
2. Leia Philosophy + Principles (30 min)
3. Leia MentalModels (30 min)
4. Depois, seção relevante à sua função

**Para revisão de decisões:**
1. Sempre comece por Principles
2. Cruze com ProductDNA (o que é imutável?)
3. Verifique em 11 — Decisions se já foi tratado
